# Fit a 3D panel's contents inside the panel at draw time

Fit a 3D panel's contents inside the panel at draw time

## Usage

``` r
# S3 method for class 'ggcube_panel_fit'
makeContext(x)
```

## Arguments

- x:

  A `ggcube_panel_fit` gTree.

## Value

The gTree, with a viewport that scales its contents to fit.
